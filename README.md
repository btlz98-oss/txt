# TextCraft KR

한국어 텍스트 정리/가공/비교/인코딩/EPUB 변환 올인원 GUI 도구입니다. (PySide6)

## 설치 방법
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## 실행 방법
```bash
python main.py
```

## 기능 요약
- 문단 정리기: 괄호/영문/한자/특수문자 정리, 줄바꿈/공백 정규화
- 줄 도구: 빈 줄 제거, 구분자 기반 줄바꿈 추가/제거, 정렬, 중복 제거
- 문자/단어/줄 수 세기
- 텍스트 비교: 줄/단어/문자 단위 색상 Diff
- HTML 엔티티/URL 인코딩 변환
- TXT→EPUB 단건 변환
- EPUB 일괄 변환기(파일/폴더/드래그 앤 드롭/진행률/결과 테이블)

## 드래그 앤 드롭 사용법
- TXT→EPUB 탭: `.txt` 파일 하나 드롭
- EPUB 일괄 변환기 탭: txt 파일/폴더 드롭 가능
- 잘못된 형식은 자동 무시되고 상태바 메시지로 안내

## 폴더 일괄 변환 사용법
1. EPUB 일괄 변환기 탭에서 **폴더 추가**
2. 필요 시 **하위 폴더 포함** 체크
3. 출력 폴더, 공통 저자/언어, 스타일 템플릿 설정
4. **일괄 변환 실행**

## EPUB 스타일 템플릿 설명
- 기본형: h1 1.6em, bold, 좌측 정렬
- 소설형: h1 중앙 정렬/큰 여백, 문단 들여쓰기(첫 문단 제외)
- 에세이형: 절제된 제목, 여유 있는 line-height
- 웹문서형: 큰 제목, 넓은 문단 간격
- 아동도서형: 더 큰 제목, 읽기 쉬운 넓은 간격
- 사용자 정의형: UI에서 제목/본문 스타일 직접 입력

## 문제 해결
- 인코딩 문제: UTF-8 실패 시 cp949 자동 재시도
- 변환 실패: delimiter 모드에서 구분 문자열 누락 여부 확인
- 빈 제목 문제: 제목이 비어 있으면 파일명으로 자동 생성

## 샘플 테스트용 TXT
```text
제1장 시작

안녕하세요. TextCraft KR 테스트 문장입니다.
두 번째 줄입니다.

제2장 전개

여기는 다음 장입니다.
```

## 샘플 EPUB 변환 시나리오
1. TXT→EPUB 탭에서 txt 파일 선택
2. 분리 방식 `blankline` 선택
3. 스타일 `소설형` 선택
4. 출력 폴더 지정 후 변환
5. 로그에서 입력/출력/성공 상태 확인
